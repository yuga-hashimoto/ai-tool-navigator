# Tool of the Week Post Template

Use this template when creating new "Tool of the Week" posts.

## Front Matter (YAML)
```yaml
---
title: "[Tool Name]"
slug: "tool-of-the-week-[date]-[tool-slug]"
date: "YYYY-MM-DD"
author: "AI Tool Navigator Team"
excerpt: "A compelling 2-3 sentence description that includes primary keywords and hook."
tags: ["Tool of the Week", "Category Name", "Keyword1", "Keyword2"]
tool_of_the_week: true
featured: true
---
```

## Content Structure

### 1. Introduction (100-150 words)
- **Hook**: Start with a compelling statement about the problem this tool solves
- **Primary Keyword**: Include main keyword in first paragraph
- **Value Proposition**: Briefly state why this tool is worthy of "Tool of the Week"

### 2. What is [Tool Name]? (150-200 words)
- Define the tool and its purpose
- Include founding/company information if relevant
- Mention key differentiators

### 3. Key Features (300-400 words)
- 3-5 key features with sub-bullets
- Focus on unique capabilities
- Include specific metrics where possible

### 4. Use Cases & Monetization Potential (200-300 words)
- Real-world applications
- Business/monetization angles
- Target audience

### 5. Pricing & Plans (100-150 words)
- Free tier details
- Paid tier pricing
- Commercial rights
- Value analysis

### 6. Pros & Cons (100-150 words)
- 3-4 pros with explanations
- 2-3 cons with explanations

### 7. Comparison with Competitors (200-300 words)
- Compare with 2-3 main competitors
- Use comparison table
- Highlight unique advantages

### 8. Getting Started (100-150 words)
- Quick start steps
- Best practices
- Tips for success

### 9. Related Tools (50-100 words)
- Link to 3-4 related tools in the database
- Use internal links format: `[Tool Name](/tools/[slug])`

### 10. Conclusion (100-150 words)
- Summary of why this tool is recommended
- Call to action
- Final thought

## SEO Requirements

### Keywords to Include
- Primary keyword: [tool name] review
- Secondary keywords: [category] tools, [specific use case]
- Long-tail keywords: [specific feature] for [audience]

### Internal Links Strategy
- Link to related tools: 3-4 links
- Link to category pages: 1-2 links
- Link to previous Tool of the Week posts: 1-2 links

### Meta Description (for SEO plugins)
- 150-160 characters
- Include primary keyword
- Add call to action
