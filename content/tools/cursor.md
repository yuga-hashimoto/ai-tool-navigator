## What is Cursor?

Cursor is an AI-powered code editor designed to make you more productive. It is a fork of VS Code, so all your extensions work out of the box.

### Key Features

*   **Chat with Codebase:** Ask questions about your entire repo.
*   **Copilot++:** Predicts your next edit.
*   **Docs integration:** Add documentation for libraries you use.

### Why use Cursor?

If you want an IDE that truly understands your code, Cursor is the way to go.
