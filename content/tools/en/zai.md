## What is Z.ai (GLM Coding Plan)?

Z.ai's GLM Coding Plan is a developer-focused subscription that lets you use GLM family models inside tools like Claude Code, Cline, Roo Code, and OpenCode. It is positioned as a coding workflow plan rather than a generic chat subscription.

## Key strengths

### 1. Broad tool compatibility

Z.ai documents setup flows for Claude Code, OpenCode, Roo Code, Goose, Cline, and similar tools. The `@z_ai/coding-helper` package reduces setup friction if you want a guided installation flow.

### 2. Easier budget control

Instead of pure usage-based billing, the Coding Plan uses quota-based subscriptions. That makes it easier to estimate monthly cost before you roll it out across daily coding sessions.

### 3. Friendly for affiliate-style content

Z.ai also documents an invitation campaign for new users. If someone signs up and completes the first payment in the required window, the referral flow can apply a discount.

## Pricing note

Official docs still show Lite and Pro pricing, while some public-facing pages use different marketing copy. Treat the checkout screen as the source of truth before publishing exact numbers.

## Bottom line

Z.ai is a strong fit if you already like agentic coding tools and want a lower-cost GLM-based backend with a clear referral CTA.
