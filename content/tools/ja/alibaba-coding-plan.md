## Alibaba Cloud Model Studio Coding Planとは？

Alibaba Cloud Model Studio の Coding Plan は、Qwen Code や Claude Code、Cline、Cursor、Roo Code などのコーディングツール向けに最適化された定額プランです。通常の Model Studio API と分けて運用できるため、開発ワークフローの費用を読みやすく管理できます。

## 主な特徴

### 1. Qwen Code を正面から使いやすい

Alibaba 側が Qwen Code の公式ガイドを用意しており、CLI やエディタ拡張で導入しやすいのが大きな強みです。Qwen 系モデルを軸にしたいなら相性が良い導線です。

### 2. 月額制で回しやすい

Proプラン（月額$50）の課金なので、従量課金の API よりコストを読みやすく、検証や日常開発へ載せやすい設計です（注：2026年3月20日以降、Liteプランの新規申し込みは停止されています）。

### 3. 複数モデルを選べる

公式ドキュメントでは Qwen に加えて GLM、Kimi、MiniMax などのモデル群も案内されています。ひとつの契約で比較しながら運用しやすいのは魅力です。

## 注意点

Coding Plan 用の API キーと Base URL は、通常の Model Studio API とは別です。バックエンドの自動処理や一般 API 用途を想定している場合は、通常プランと役割を分けて考える必要があります。

## 結論

Alibaba の Coding Plan は、Qwen Code を本命にしつつ、固定費で複数モデルを試したい開発者に向いています。特に CLI ベースの開発フローと相性が良い選択肢です。
