## Z.ai (GLM Coding Plan)とは？

Z.ai の GLM Coding Plan は、Claude Code、Cline、Roo Code、OpenCode などのコーディングツールから GLM 系モデルを扱うための開発者向けサブスクリプションです。単純なチャット課金ではなく、コーディング用途に寄せた専用プランとして提供されています。

## 主な特徴

### 1. 主要エージェントをそのまま使いやすい
公式ドキュメントでは Claude Code、OpenCode、Roo Code、Goose、Cline などの利用フローが案内されており、`@z_ai/coding-helper` を使ってセットアップを補助できます。既存の開発フローを変えずに導入しやすいのが強みです。

### 2. 予算管理しやすいプラン型
公式案内では Lite と Pro の 2 プランが用意され、一定時間ごとにクォータがリセットされる構成です。従量課金の API より、月ごとのコスト上限を読みやすい運用がしやすくなります。

### 3. 招待リンクの導線を作りやすい
新規ユーザーが招待リンク経由で登録し、規定時間内に初回支払いを完了すると割引が適用されるキャンペーンが案内されています。記事から直接リンクしやすい商材です。

## 料金メモ

公式ドキュメントには Lite `$3`、Pro `$15` の案内がありますが、トップページや購入導線では別表記が見えることがあります。価格表示は更新中の可能性があるため、最終的な請求額は必ず購入画面で確認してください。

## 向いている人

* Claude Code や Cline のバックエンドコストを抑えたい人
* GLM 系モデルを定額で試したい人
* 招待リンク付きで紹介記事を作りたいアフィリエイト運用者

## 結論

Z.ai は、既存のコーディングエージェントを保ったまま GLM 系モデルを安定運用したい人に向いています。特に「まずは低コストで回しながら、記事から招待リンクにも送客したい」という用途と相性が良いサービスです。
